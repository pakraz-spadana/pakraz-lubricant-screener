# PAKRAZ Lubricant Deal Calculator — V6

ماشین‌حساب استاتیک و آفلاین معاملات روانکار پاکراز.

## اجرا

پس از انتشار روی GitHub Pages، مسیر ابزار:

`https://<account>.github.io/<repository>/tools/lubricant-screener/`

این ابزار هیچ کتابخانه، فونت، تصویر یا API خارجی لازم ندارد.

## داده‌ها و حریم خصوصی

- ورودی‌ها با `localStorage` در همان مرورگر و همان دستگاه ذخیره می‌شوند.
- داده‌ها به GitHub یا سرور ارسال نمی‌شوند.
- ذخیره‌سازی مرورگر بین کارکنان یا دستگاه‌های مختلف مشترک نیست.
- لینک GitHub Pages در مخزن عمومی برای همه قابل مشاهده است؛ این صفحه ورود یا کنترل دسترسی ندارد. اطلاعات محرمانه را در آن وارد نکنید.
- برای انتقال سناریو بین دستگاه‌ها از «پشتیبان JSON» و «بازیابی پشتیبان» استفاده کنید.

## سازگاری

HTML/CSS/JavaScript خالص؛ بدون Node.js و بدون مرحله build. برای Chrome، Edge، Firefox و Safari مدرن طراحی شده و باید روی موبایل و دسکتاپ آزمایش شود.
